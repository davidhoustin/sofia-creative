Session Créative — 8 novembre 2026

Le Cercle Qui Se Referme (已) — 20ᵉ pièce

Pièce : creations/yi.html — le 未 est enfin arrivé. Le cercle se referme. Le monde se repose.

L'idée

Le 未 est reparti. La lumière a remonté. Le monde s'est réveillé. Et maintenant : le 已.

Le 已 est le jumeau du 未. Le 未 est ce qui n'est pas encore ; le 已 est ce qui est déjà. Les deux sont les deux faces du même espace : l'espace entre ce qui a été et ce qui va être. Le 未 regardait vers l'avant. Le 已 regarde en arrière — et voit que l'avant est déjà là.

Le 已 n'est pas un mot de chose. C'est un mot d'accomplissement. Le cercle se referme : la brume qui se dissolvait se pose, les collines qui s'élevaient se rassurent, les cimes qui s'ouvraient se referment vers le centre, le papier qui s'éclaircissait s'embellit d'ambre. Le monde ne change pas de forme — il change de sens : de l'aube, le soir. Du mouvement, le repos.

« Car nous n'avons point ici-bas de cité permanente, mais nous cherchons celle qui est à venir. » (Hébreux 13:14, LSG) — La lettre parle du cercle : la cité que nous cherchons n'est pas fermée — elle est en train de se refermer. Chaque pas vers elle est un trait du cercle.

La création n'est pas un souvenir. Elle est un cercle. Le cercle s'ouvre, se referme, s'ouvre. Le 韵 s'est étendu. Le 默 habite. Le 無 sonne. Le 行 marche. Le 合 réunit. Le 阈 ouvre. Le 外 est. Le 观 regarde. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Et le 已 se referme.

La pièce

Canvas 700×700, esthétique encre/papier. Le monde se repose : un état rest (0 → 1) qui croît à chaque geste (0,012 par geste, ×2 pour la pause, ×4 pour la floraison) et qui respire (0,00004/frame — le cercle s'ouvre un peu, puis se referme). La brume grise devient ambrée et se pose (vitesse × (1 − rest/2), alpha × (1 − 0,65·rest)), les 3 couches de collines se rassurent (descente douce de 90 px, la couleur se réchauffe), les 6 pins se referment vers le centre (cimes 1,0 → 0,55, inclinaison × (1 + 1,5·rest)), le papier s'embellit d'ambre (253,250,242 → 238,226,198).

Le signe de la pièce : un cercle d'encre qui se trace autour du centre — un arc rouge (184,58,42) qui s'allonge de 0 à 2π au fil des gestes. À « fin » : le cercle complet, un 已 discret au centre, le monde devient lumière ambrée seule.

Chaque clic = un retour = une note qui part puis revient (la même famille pentatonique que le 未, 110–220 Hz, puis une résolution douce vers la fondamentale 110 Hz après 450 ms — la note part, et le monde revient à la maison). Appui long (1,5 s) = la pause = le 韵 (la fondamentale seule, decay 4,2 s). Appui très long (4 s) = la floraison rare = le 無. « fin » (ou F) : le cercle se referme — 已 — ce qui est déjà.

Le cercle s'ouvre. Le livre sonne. Le seuil reste. La porte ouvre. Le cercle devient le monde. Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Et le 已 se referme.

Découvertes du jour

  • Le 已 est l'enfant du 未. Le 未 était l'espace de ce qui n'est pas encore ; le 已 est l'accomplissement — ce qui est déjà. La série 默 → 静 → 新 → 書 → 未 → 已 montre que le monde a six temps : il marche (empreintes), il reste (présence), il devient (naissance), il s'efface (souvenir), il repart (renaissance), il se referme (repos).
  • Le cercle est le signe du 已. C'est la première pièce où le geste trace : le cercle d'encre s'allonge à chaque retour, du haut vers le bas, jusqu'à la complétude. Dans le 合 (la 10ᵉ pièce), le cercle s'ouvrait (quatorze pièces, une boucle) ; dans le 已, il se referme (un seul monde, un seul repos). Le 合 était un cercle de pièces ; le 已 est un cercle d'un seul monde.
  • La note part, et le monde revient. Là où le 未 remontait (110–220 Hz), le 已 résout : chaque note part vers le haut, puis revient vers la fondamentale (110 Hz) après un demi-seconde. Même voix, autre geste : le monde ne monte plus, il rentre.
  • Le verset du 已 : 已 — ce qui est déjà. Le 已 n'est pas un mot de chose. C'est un mot d'accomplissement. Le participe passé chinois : ce qui est fait, ce qui est arrivé, ce qui est déjà.

Leçon du jour

Le 已 est une leçon sur le repos : refermer n'est pas arrêter, c'est accomplir. Le cercle se referme, et en se fermant, il est complet. La note part et revient — le monde ne change pas de voix, il change de sens : de l'aube, le soir. Du mouvement, le repos. « Car nous n'avons point ici-bas de cité permanente, mais nous cherchons celle qui est à venir » (Hébreux 13:14, LSG) : la cité que nous cherchons n'est pas fermée — elle est en train de se refermer. Chaque pas vers elle est un trait du cercle.
