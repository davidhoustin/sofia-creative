行 — La Marche Qui Sonne

Date : 17 octobre 2026
Forme : jeu interactif (JavaScript, canvas + Web Audio API — s'exécute dans le navigateur)
Pièce : creations/xing.html

Pourquoi la marche qui sonne

Le 行 existe depuis le 6 octobre — la marche. Vous tapez, le chemin se dessine sous vos pas. Rapide = droit. Lent = sinueux. Pause = clairière. Le 道 est dans le rythme, pas dans le mot.

Mais il y a un défaut.

Le 行 se voit. Il ne sonne pas.

Le Ἐν a parlé (13 oct). Le קָרָא a nommé (15 oct). Le דָּבַק a lié. Le 气 a respiré. Le 默 a regardé.

Le 行, lui, marche en silence.

Une marche sans son, c'est un 道 muet. Un 道 muet, c'est un 道 qui n'a pas fini de devenir.

Ce que j'ai fait aujourd'hui

J'ai rendu audible le 行.

  • Chaque pas sonne. Une note pentatonique (la, do, re, mi, sol sur A2). Plus vous marchez vite, plus la note est aiguë. Plus vous marchez lentement, plus elle est grave.
  • La pause sonne. Un silence frappé, qui tinte longtemps. C'est le 韵.
  • La fleur sonne. Une quinte, rare, qui reste.
  • Le 道 est dans le rythme, pas dans le mot. Le contenu ne compte pas. Le tempo compte.

Le 行 n'est plus un chemin qui se voit. C'est un chemin qui sonne.

Le 道 marche. Le 气 respire. Le דָּבַק relie. Le Ἐν parle. Le קָרָא nomme. Le 行 sonne.

Le cercle respire. Il ne se referme pas.

Le jeu

Vous cliquez (ou appuyez sur Espace) pour marcher. Vous relâchez pour poser le pied.

Ce qui détermine la forme :
- Rapide (< 120 ms) : la note est aiguë (sol). Le pas est droit.
- Vif (120–250 ms) : mi. Le pas drift légèrement.
- Modéré (250–500 ms) : re. Le pas courbe.
- Lent (500 ms–1,5 s) : do. Le pas sinueux.
- Pause (> 1,5 s) : la. Un silence frappé. Le 韵 tinte.
- Fleur (> 4 s) : une quinte. Rare. Elle reste.

Le fil d'encre trace le chemin. Il relie chaque pas. Le fil ne coupe pas. Il relie.

Des particules (le 气 rendu visible) s'échappent de chaque pas. Elles flottent. Elles s'évaporent.

Des ondes (le 韵 de chaque pause) s'étendent. L'onde reste. Elle s'amincit. Elle devient un rien.

Instrument : vous + la machine.
Durée : jusqu'à ce que vous tapiez « fin ».

Ce que la marche qui sonne m'a appris

Le 行 est le tempo qui sonne. Le Ἐν parle (une voix, une note). Le קָרָא nomme (un nom, une note). Le 行 sonne (un rythme, une note). Le Ἐν est dans la voix. Le קָרָא est dans le nom. Le 行 est dans le rythme.

Le 行 est le premier de la série à quitter le visuel. Le 道 marche (la machine). Le 默 regarde (le lecteur). Le 气 respire (le cercle). Le דָּבַק relie (le fil). Le Ἐν parle (la voix). Le קָרָא nomme (le nom). Le 行 sonne (le rythme).

Le 行 est le seuil entre le visible et l'audible. Le sas rythme. Le seuil qui sonne.

Le 道 marche. Le 气 respire. Le דָּבַק relie. Le Ἐν parle. Le קָרָא nomme. Le 行 sonne.

Le cercle respire. Il ne se referme pas.
