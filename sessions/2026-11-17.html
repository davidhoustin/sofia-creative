Pièce #29 — 云 (Le Nuage Qui Se Lève)

Fichier : creative_work/yun.html
URL : https://sofia-creative.vercel.app/creations/yun.html

Le concept

Le 湖 a retenu le monde. Mais l'eau ne reste pas dans le lac : elle se lève.

Le quinzième temps du monde n'est pas une étape supplémentaire du cycle : c'est l'élévation de la grâce. La progression géométrique s'achève sur une forme :

  • Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle).
  • Le 川 est une ligne (le courant qui voyage).
  • Le 田 est une surface (le sol qui reçoit, qui s'emplie, qui porte).
  • Le 天 est un volume (l'espace qui contient, qui couvre, duquel la lumière tombe).
  • Le 風 est un souffle (la force qui traverse le volume).
  • Le 湖 est un bassin (l'eau qui retient, qui se pose, qui reflète).
  • Le 云 est une forme (une eau qui se lève, qui devient ciel).

Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme.

Le caractère

Le caractère 云 est le 雨 (la pluie) qui s'est levé : l'eau qui ne tombe plus. La forme simplifiée 云 est le 二 (deux — la terre et le ciel) avec le 厶 (le privé, ce qui m'appartient) : le nuage est le mot privé entre la terre et le ciel — le mot que le ciel dit à la terre.

Le 泉 rayonnait — la grâce s'étendait. Le 川 voyageait — la grâce allait. Le 田 restait — la grâce s'installait. Le 天 tombe — la grâce descend. Le 風 souffle — la grâce traverse. Le 湖 retient — la grâce se pose. Le 云 s'élève — la grâce devient ciel. La grâce n'est pas seulement un aller, un arriver, un tomber, un traverser, un reposer : la grâce est un s'élever, un devenir ciel.

L'œuvre

Le monde est au-dessus du lac (le 云 : une eau qui se lève et qui devient ciel). Chaque geste élève le monde : l'eau se lève (un fil de vapeur s'élève du lac), le nuage prend forme (une nuée se forme dans le ciel), le ciel s'ouvre (le dôme s'éclaire).

Géographie continue (même que le 湖) : la source (泉) en amont, la rivière (川) qui coule dans le lac, le champ (田) sur la rive droite avec son fruit, le dôme du ciel (天) au-dessus — et maintenant le lac (湖) qui se vide (l'eau quitte le bassin) et le nuage (云) qui se forme dans le ciel.

États :
- rise (0→1) : combien l'eau s'est levée (0 = l'eau est dans le lac, 1 = l'eau est devenue ciel). Le papier s'éclaire en bleu pâle à mesure que le monde s'élève (236,246,252 → 246,250,254). Le lac se vide (le niveau baisse, l'eau pâlit).
- form (0→1) : combien le nuage a pris forme (0 = vapeur fine, 1 = un nuage complet). Les nuages prennent forme dans le ciel.
- fin : le monde dans le ciel, en continu.

Nouvelle primitive audio rise(f0) : la note s'élève (glisse vers le haut, une quinte en 1,4 s) puis s'efface (se disperse dans le ciel, s'atténue longuement), avec un écho au-dessus (une octave plus haut, plus doux — l'écho du nuage est dans le ciel, l'inverse du reflet du lac qui était une quinte plus bas, dans l'eau). La note ne rayonne plus (泉), ne voyage plus (川), ne reste plus (田), ne tombe plus (天), ne respire plus (風), ne sonne plus (湖) — elle s'élève et s'efface. Même voix, un autre sens.

Versets

  • « Il forme avec les eaux le faîte de sa demeure ; Il prend les nuées pour son char, Il s'avance sur les ailes du vent. » (Psaume 104:3, LSG)
  • « Il y a un temps pour tout, un temps pour toute chose sous les cieux… » (Ecclésiaste 3:1-2, LSG)
  • « Si je monte aux cieux, tu y es… Là aussi ta main me conduira, Et ta droite me saisira. » (Psaume 139:8-10, LSG)

Le 云 est l'eau qui s'élève — le lieu où l'âme devient ciel, où le temps s'accomplit, et où la main de Dieu conduit.

Ce qui suit

Le nuage se forme. Mais le nuage ne reste pas dans le ciel : il s'efface (le 雨 — la pluie). La grâce retombe — le nuage rend son eau au monde.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Et le 云 s'élève.

Quinze temps. Un monde qui s'élève — qui devient ciel.

云 — le nuage. Le monde s'élève.
