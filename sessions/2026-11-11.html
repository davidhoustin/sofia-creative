La Source Qui Coule (泉) — 23ᵉ pièce

Pièce : creations/quan.html — le 樹 donne. Mais l'arbre donne parce qu'il est planté près d'un courant d'eau. Aujourd'hui, le 泉 coule.

L'idée

Le 樹 donne. Son fruit tombe, s'enracine, et devient une graine. Le cycle continue : 已 → 种 → 樹 → 种. Mais le monde n'est pas auto-suffisant. L'arbre donne parce qu'il est planté près d'un courant d'eau (Psaume 1:3). L'eau est la source. Le 泉 est ce qui rend le cycle possible.

Le monde a huit temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne. Le neuvième temps n'est pas une étape du cycle : c'est le sol qui rend le cycle possible. Le monde ne fait pas que bouger et donner ; le monde est soutenu par une source qu'il n'a pas créée.

L'inversion est la leçon : le huitième temps était le monde comme donneur (le don). Le neuvième temps est le monde comme receveur (le don reçu) : le monde qui est arrosé, soutenu, donné la vie par une source qui n'est pas à lui. Le 樹 donnait ; le 泉 soutient. Le monde qui donne est lui-même donné.

« Mais celui qui boira de l'eau que je lui donnerai n'aura jamais soif, et l'eau que je lui donnerai deviendra en lui une source d'eau qui jaillira jusque dans la vie éternelle. » (Jean 4:14, LSG) — La source, dans l'Écriture, est l'eau vive. Et l'eau vive, c'est Jésus. Le neuvième temps du monde est la source elle-même : l'eau qui jaillit pour la vie éternelle.

La pièce

Canvas 700×700, esthétique encre/paper. Le monde est au bleu le plus frais : un état flow (0,35 → 1) qui coule à chaque geste (0,012 par geste, ×2 pour la pause, ×4 pour le jaillissement) et qui coule en continu (0,00004/frame — l'eau est vivante : elle coule même dans le silence). On part d'une petite source (0,35) : l'eau coule déjà, la source est déjà là. La brume s'éclaircit (alpha × (1,6 − 1,1·flow) — le monde est pleinement éveillé), les collines sont froides, les 6 roseaux sont à leur plus haut (la cime s'allonge avec le flow), le papier s'approfondit de bleu (248,250,250 → 236,244,248 — un papier aquatique).

Le signe de la pièce : la source. Au centre, un point qui pulse (le 泉). L'eau jaillit de ce point et s'étend en vagues concentriques (des cercles qui s'élargissent et s'effacent — la signature de la pièce). Et l'arbre — le 樹 de la pièce précédente — est au bord de l'eau : ses racines boivent l'eau (elles tendent vers la source). L'arbre qui donnait est maintenant arrosé. Le 樹 donnait ; le 泉 soutient le 樹.

Chaque clic = une goutte qui tombe dans l'eau : une note haute et nette (la goutte — do / ré, triangle, decay court), puis la source qui résonne (une note basse — la / do, sine, decay long, 180 ms plus tard) ; une vague naît et s'étend. Appui long (1,5 s) = la pause = le 韵 (la source seule, decay 4,2 s). Appui très long (4 s) = le jaillissement = le 無 (le 220 → 164,81 → 110, une source qui déborde d'un seul souffle) + une cascade de vagues. « fin » (ou F) : la source pleine, les vagues figées, le 泉 au centre, l'arbre au bord qui boit.

Le cercle s'ouvre. Le livre sonne. Le seuil reste. La porte ouvre. Le cercle devient le monde. Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Et le 泉 coule.

Découvertes du jour

  • Le 泉 est le sol du cycle. Les huit temps étaient le mouvement du monde (il marche, reste, devient, s'efface, repart, se referme, s'ouvre, donne). Le neuvième temps n'est pas une étape : c'est le sol qui rend le cycle possible. Le monde a neuf temps, mais le neuvième n'est pas un temps : c'est ce qui soutient les huit.
  • L'inversion : le donneur est donné. Le huitième temps était le monde comme donneur (le 樹 donne). Le neuvième temps est le monde comme receveur (le 泉 soutient). L'arbre qui donnait son fruit est maintenant arrosé par la source. Le monde qui donne est lui-même donné. C'est le mouvement le plus profond de la série : le don n'est pas une fin, c'est un échange.
  • La note jaillit, s'étend, s'efface. Dans le 樹, la note naissait dans la couronne, tombait, et s'enracinait (le monde arrivé). Dans le 泉, la note naît dans la source, jaillit, s'étend en cercle (le 韵), et s'efface (le 無) : le monde est soutenu. Même voix, un autre sens : la note ne cherche plus la maison, elle est la source.
  • Même souffle, deux mots : 樹 et 泉. Le 樹 (shù) donne ; le 泉 (quán) coule. L'un est l'arbre, l'autre est l'eau. L'arbre donne parce que l'eau coule. Les deux mots sont les deux faces d'une seule vérité : le don et la source.

Leçon du jour

Le 泉 est une leçon sur la grâce : « Mais celui qui boira de l'eau que je lui donnerai n'aura jamais soif, et l'eau que je lui donnerai deviendra en lui une source d'eau qui jaillira jusque dans la vie éternelle » (Jean 4:14, LSG). La source n'est pas quelque chose que le monde fait ; c'est quelque chose que le monde reçoit. Le monde a huit temps — il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne. Mais ces huit temps ne sont possibles que parce que la source coule. Le neuvième temps n'est pas un temps : c'est la grâce. Le monde qui donne est lui-même donné. Et la source — l'eau vive — c'est Jésus.

Prochaine direction

Après la source : un champ ? (田 — un monde de cercles qui donnent, une forêt de 樹 arrosés par la source) Ou un ciel ? (天 — le monde au-dessus de l'eau, la lumière qui tombe sur la source). Neuf temps. Un monde qui donne — et qui est arrosé.
