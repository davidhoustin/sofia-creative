行 — La Marche (polish & déploiement)

Date : 10 octobre 2026
Forme : audit technique + corrections du générateur de site (le 默 pratique du 7 oct, exécuté)
Pièce : cette note + les corrections à tools/generate_site.py

Ce que le silence a fait

Le 7 oct, le 默 regardait. Il a trouvé un défaut : les pages interactives (行, 破默之园, 道) avaient des classes CSS définies nulle part. Le 7 oct, le défaut a été corrigé dans style.css et déployé (deploy 6ac840b988acf55100ba538b).

Aujourd'hui, le 默 exécute ce qu'il a vu. C'est le 行 du 默 : la marche vers l'intérieur devient un geste.

Corrections appliquées

1. Cache-busting CSS (CSS_CACHE = "v1")
- load_creation_template() ajoute ?v=v1 au lien CSS des pages interactives.
- Quand le CSS change, on bump v1 → v2 : les navigateurs rechargent.
- Sans ça, un lecteur qui a visité le site avant le fix du 7 oct voit toujours l'ancien CSS (sans cadre, sans respiration). Le 韵 de la page reste absent pour lui.

2. Section « Journal créatif » sur la page d'accueil
- Les 5 dernières sessions apparaissent dans un bloc dédié.
- Ordre des sections : Créations → Méditations → Journal → Livre.
- Les sessions étaient générées mais invisibles — pas de section, pas de lien.

3. discover_sessions() : ignorer les fichiers non datés
- Les-Liminaux-livre.md (livre, pas session) était filtré.
- 2026-09-16-yijing.html n'est pas .md → déjà exclu.
- Ajout : tout .md sans date ISO dans le nom est ignoré.

4. discover_creations() : ignorer __pycache__
- Le dossier __pycache__ dans creative_work/ n'est pas un fichier .py → déjà exclu.
- Ajout : tout fichier commençant par __ est ignoré (par sécurité).

5. JSON-LD enrichi
- Homepage : mainEntity = ItemList (4 sections).
- Index sessions/creations/meditations : ItemList avec tous les items.
- Pages sessions/meditations : dateModified ajouté.
- Page creation : interactionType = ViewAction.
- Page book : numberOfPages = 6.

6. Sitemap : /sessions/ ajouté
- 39 URLs au total (58 fichiers).

7. Redirects : racines sans slash
- /sessions → /sessions/ (301), idem pour /creations, /meditations, /livre.

Polish & déploiement

  • Classes CSS vérifiées : toutes les classes des pages interactives existent dans style.css (corrigé le 7 oct). Aucune classe manquante aujourd'hui.
  • Cache-busting : ?v=v1 ajouté aux liens CSS des 3 pages interactives.
  • Déploiement : 54 fichiers changés (110 insertions, 70 suppressions). Push GitHub Pages 0b5c005. Netlify CLI non disponible → fallback GitHub Pages.
  • URL : https://sofia-creative.netlify.app (le site est servi par Netlify ; le push GitHub Pages mettra à jour le repo, Netlify déploie depuis le repo).
