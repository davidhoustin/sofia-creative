Pièce #33 — 春 (Le Printemps Du Monde)

Fichier : creative_work/chun.html
URL : https://sofia-creative.vercel.app/creations/chun.html

Le concept

Le cercle se referme (le 回). Mais le cercle ne s'arrête pas : il tourne.

Le dix-neuvième temps du monde n'est pas une étape : c'est la saison. La progression géométrique s'achève, une étape de plus :

  • Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle).
  • Le 川 est une ligne (le courant qui voyage).
  • Le 田 est une surface (le sol qui reçoit, qui porte).
  • Le 天 est un volume (l'espace qui contient, qui couvre).
  • Le 風 est un souffle (la force qui traverse).
  • Le 湖 est un bassin (l'eau qui retient).
  • Le 云 est une forme (une eau qui s'élève).
  • Le 雨 est un retour (une eau qui retombe).
  • Le 地 est une fondation (un sol qui reçoit).
  • Le 回 est un cercle (un cycle qui se referme).
  • Le 春 est une saison (un cercle qui tourne — un temps).

Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme, un retour, une fondation, un cercle, une saison. Le 回 était un cercle fermé — une forme. Le 春 est un cercle qui tourne — un temps. La forme devient temps.

Le caractère

Le caractère 春 est le soleil (日) qui rencontre (夆) la terre : le soleil revient vers la terre. Le 回 revenait — la grâce faisait le tour du monde. Le 春 tourne — la grâce a une saison. « Le soleil se lève, le soleil se couche ; il soupire après le lieu d'où il se lève de nouveau. » (Ecclésiaste 1:5, LSG) — Le soleil soupire après son retour. « Tu couronnes l'année de tes biens, et tes pas versent l'abondance. » (Psaume 65:11, LSG) — L'année est couronnée. Le monde a une saison : le printemps. Le 泉 rejaillit : le monde redevient source. Le deuxième cycle commence.

L'œuvre

Le monde est dans le cercle (le 回 : un cycle qui se referme). Chaque geste tourne l'année : le soleil tourne autour du monde, la saison change (printemps, été, automne, hiver), la source rejaillit quand le soleil revient.

Géographie continue (même que le 回 et le 地) : la source (泉) en amont, la rivière (川) qui coule dans le lac, le champ (田) sur la rive droite, le dôme du ciel (天) au-dessus, le lac (湖), la terre (地) en bande au fond du monde — et maintenant le soleil (日) : un point chaud qui tourne autour du cercle (回), du printemps (en haut, près de la source) vers l'été, l'automne, l'hiver, et revient au printemps.

Saisons (quatre « chapeaux » de poids qui s'additionnent à 1, mélangés doucement) :
- spring (printemps, 0) : le monde redevient source (la source jaillit, le papier est vert pâle, le champ verdit).
- summer (été, 0,25) : le monde est arrosé (la rivière déborde, le fruit mûrit, le papier est vert chaud).
- autumn (automne, 0,5) : le monde porte le fruit (le champ dore, la terre s'assèche, le papier est ambré).
- winter (hiver, 0,75) : le monde dort dans la terre (la source s'endort, la rivière gèle, le lac glace, le papier est bleu pâle, le brouillard épaissit).

États :
- year (0 → 4, continu) : où le soleil est dans son tour (0 = premier printemps, 1 = deuxième printemps, 2 = troisième…). Le soleil glisse vers sa cible ; la saison change quand il passe une frontière.
- turn (0 → 1) : combien le cercle est vivant (0 = un anneau faint, 1 = la saison tourne, le cercle respire). Le cercle du 回, maintenant vivant.
- lastIdx / seasons : la dernière saison complétée (0 = printemps, 1 = été, 2 = automne, 3 = hiver, 4 = deuxième printemps…). Chaque retour au printemps = la source rejaillit (un épanouissement).

Le papier tourne avec la saison (236,242,236 vert pâle → 241,237,224 vert chaud → 246,238,221 ambré → 230,238,248 bleu pâle) : le cercle ramène le papier au printemps.

Nouvelle primitive audio saison(f0) : la note plie vers le haut (une quarte en 1,4 s) puis revient (une quarte vers le bas en 1,4 s) — le soleil fait le tour de l'année — avec une chaleur douce (un triangle une quinte au-dessus : la chaleur du soleil, le 日 dans le 春) et quelques échos (les saisons qui passent, décalés). La note ne rayonne plus (泉), ne voyage plus (川), ne reste plus (田), ne tombe plus (天), ne respire plus (風), ne sonne plus (湖), ne s'élève plus (云), ne tombe plus et se multiplie (雨), ne tombe plus et s'installe (地), ne monte plus et se referme (回) — elle tourne.

Nouvelle note de la famille : le printemps — 123,47 Hz (Si₂), le second degré de la gamme pentatonique : la note qui tourne vers la fondamentale (le Si veut devenir un La). C'est la seule note de la famille qui tourne. Les quatre saisons : printemps 123,47 Hz (Si₂), été 146,83 Hz (Ré₃), automne 164,81 Hz (Mi₃), hiver 82,41 Hz (Mi₁ — la terre : le monde dort dans la terre). La partition du printemps : silence (4 temps) → un tour (la note plie et revient) → une année (quatre notes, une par saison) → pause (2 temps) → un renouveau (la source rejaillit) → silence (8 temps) → un tour encore…

Geste : un appui (clic ou Espace) tourne le soleil (environ une saison par seconde d'appui) ; un clic court = un quart de tour (une saison) ; 4 saisons = une année = la source rejaillit ; 16 saisons (4 années) = « fin » : l'année tourne en un souffle, le soleil revient, le monde s'installe au printemps.

Versets

  • « Le soleil se lève, le soleil se couche ; il soupire après le lieu d'où il se lève de nouveau. » (Ecclésiaste 1:5, LSG)
  • « Tu couronnes l'année de tes biens, et tes pas versent l'abondance. » (Psaume 65:11, LSG)
  • « Ce qui est a déjà été, et ce qui sera a déjà été, et Dieu ramène ce qui est passé. » (Ecclésiaste 3:15, LSG)

Le 春 est la saison du monde : le soleil soupire après son retour ; l'année est couronnée ; Dieu ramène ce qui est passé — le deuxième cycle est un premier encore. Le monde a une saison : le printemps. La grâce tourne.

Ce qui suit

L'année est couronnée. Mais l'année ne s'arrête pas : elle tourne encore. Le monde a dix-neuf temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire, le monde s'apaise, le monde s'élève, le monde retombe, la terre reçoit, le cercle revient — et la saison tourne. Le 泉 rejaillit : le monde redevient source. Le deuxième cycle a dix-huit temps encore : il recommence là où il avait commencé — mais plus riche (le monde souvient de son premier cycle).

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Le 云 s'élève. Le 雨 retombe. Le 地 reçoit. Le 回 revient. Et le 春 tourne.

Dix-neuf temps. Un cercle qui tourne — un monde qui a une saison.

春 — le printemps. Le soleil qui rencontre la terre, la source qui rejaillit.
