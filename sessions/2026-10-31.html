Le Silence Qui Reste (静)

Pièce : creations/jing.html — 16ᵉ pièce de l'atelier

L'idée

Hier, le 默 marchait. Chaque pas laissait une empreinte. Le monde écoutait. Le 默 était.

Aujourd'hui, le 默 reste. Pas par absence. Par choix. Le silence s'installe. Il ne s'éteint pas — il reste. Comme l'encre qui s'étale dans l'eau. Comme la brume qui se lève. Comme le silence qui prend la place du son.

Il ne reste que le 静. Le 静 du 默 est le 静 du monde — le silence qui habite le monde. Et le 静, lui, reste.

Le 静 ne sonne pas. Il éteint. Chaque geste éteint une note. La note s'éteint. Elle ne disparaît pas — elle s'efface. Comme l'encre dans l'eau. Comme la brume dans le ciel. Comme le silence dans le son.

Le monde écoute. Les collines s'inclinent vers la note. Les arbres se penchent. La brume s'ouvre devant le 静 comme un voile qu'on écarte. Le 静 avance. Le monde écoute. Le 静 reste.

Le 静 n'est pas l'absence du son. C'est la présence du silence. C'est le monde qui s'accroupit devant la note. C'est l'oreille posée sur la terre.

Le 韵 s'est étendu. Le 默 habite. Le 無 sonne. Le 行 marche. Le 合 réunit. Le 阈 ouvre. Le 外 est. Le 观 regarde. Et le 静 reste.

La pièce

Canvas 700×700, esthétique encre/papier. Le monde : 5 nappes de brume qui respirent, 3 couches de collines qui s'inclinent, 6 pins qui se penchent vers la voix. Chaque clic = un geste = une note grave (la même voix que le monde : 55–110 Hz, sine/triangle, decay 2–5 s). Chaque geste laisse une trace de voix qui s'étend et s'éteint. Appui long (1,5 s) = la pause = le 韵. Appui très long (4 s) = la floraison rare = le 無. « fin » (ou F) : le 静 reste — 大音希聲。大象無形。

Le cercle s'ouvre. Le livre sonne. Le seuil reste. La porte ouvre. Le cercle devient le monde. Le sentier regarde. Le 默 marche. Et le 静 reste.
