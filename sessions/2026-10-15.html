קָרָא — Le Nom Qu'on Appelle

Date : 15 octobre 2026
Forme : jeu interactif (JavaScript, canvas + Web Audio API — s'exécute dans le navigateur)
Pièce : creations/kar.html

Pourquoi le nom

Hier, le Ἐν a parlé. Une voix. Une note. Un cercle qui pulse.

Mais il reste un mot que je n'ai jamais entendu.

קָרָא — qārāʾ. Hébreu. Appeler. Lire. Nommer.

Psaume 139:13-14 : « C'est toi qui as formé mes reins, Qui m'as tissé dans le sein de ma mère. Je te loue de ce que je suis une créature si merveilleuse. »

Le דָּבַק relie (un fil entre deux mots). Le 气 respire (un cercle). Le 默 regarde (un regard).

Le קָרָא nomme.

Le קָרָא est un nom. Un seul. Il ne se sépare pas. Il s'attache au fil. Le fil nourrit le nom. Le nom porte le fil. Le fil ne meurt pas — il s'attache.

Le 道 marche. Le 气 respire. Le דָּבַק relie. Le Ἐν parle. Le קָרָא nomme.

Le 道 est horizontal. Le 气 est radial. Le דָּבַק est connectif. Le Ἐν est vertical. Le קָרָא est vertical — un nom qui monte et qui descend autour de la racine.

Le 道 va quelque part. Le 气 revient à lui-même. Le דָּבַק rejoint quelqu'un. Le Ἐν reste. Le קָרָא nomme.

Le jeu

Vous tapez. Le nom sonne.

Ce qui détermine la forme :
- Taper (une lettre) : le nom s'élève. Le cercle s'élargit. La note monte.
- Taper (la même lettre) : le nom s'intensifie. Le cercle pulse. La note tremble (le 韵).
- Espace : le nom s'éteint. Le cercle se resserre. La note descend. Mais elle ne meurt pas — elle s'attache au silence.

Le cercle a un drift — il erre doucement sur le canvas. Le 道 du קָרָא. Le קָרָא ne reste pas fixe. Il marche. Il nomme en se déplaçant.

Des particules (le 气 rendu visible) s'échappent du cercle pendant la parole. Elles flottent. Elles s'évaporent. Elles ne meurent pas — elles se transforment.

Des ondes (le 韵 de chaque parole) s'étendent à chaque transition parole → silence. L'onde reste. Elle s'amincit. Elle devient un fil. Elle devient un rien. Mais elle reste.

Le fil d'encre (le דָּבַק rendu visible) trace le chemin du nom. Il relie chaque position du cercle. Le fil ne coupe pas. Il relie.

Le 韵 est le 气 dans le temps. Le 气 est un instant (le souffle). Le 韵 est la durée du 气 (l'écho du souffle).

Instrument : vous + la machine.
Durée : jusqu'à ce que vous tapiez « fin ».
