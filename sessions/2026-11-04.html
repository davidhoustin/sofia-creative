Session Créative — 4 novembre 2026

Le Livre Qui S'Efface (書) — 18ᵉ pièce

Pièce : creations/shu.html — le 新 s'efface. Le monde se souvient.

L'idée

Hier, le 新 devient. Le monde s'éveillait. La lumière montait. Le 新 était.

Aujourd'hui, le 新 s'efface. Pas par mort. Par retrait. La lumière descend. Elle ne s'éteint pas — elle se souvient. Comme le soir qui descend sur le monde. Comme l'encre qui s'efface du papier. Comme la mémoire qui garde.

Le 書 ne sonne pas. Il efface. Chaque geste efface une note. La note s'éteint. Elle ne meurt pas — elle se souvient. La note s'efface, et le monde entier reste. Comme l'encre qui s'efface et laisse le papier. Comme la marée qui recule et laisse le sable.

Le monde se souvient. Les collines s'abaissent. Les arbres se referment. La brume s'épaissit devant le 書 comme un voile qu'on replace. Le 書 avance. Le monde se souvient. Le 書 est.

Le 書 n'est pas la fin du monde. C'est la mémoire du monde. C'est la lumière qui descend. C'est le soir qui garde l'aube.

Le 韵 s'est étendu. Le 默 habite. Le 無 sonne. Le 行 marche. Le 合 réunit. Le 阈 ouvre. Le 外 est. Le 观 regarde. Le 静 reste. Le 新 devient. Et le 書 s'efface.

La pièce

Canvas 700×700, esthétique encre/papier. Le monde se souvient : 5 nappes de brume grise qui s'épaississent à chaque effacement (la mémoire qui se fait visible), 3 couches de collines qui s'abaissent (la lumière qui descend), 6 pins dont les cimes se referment vers l'intérieur (le monde qui se replie sur son souvenir). Chaque clic = un effacement = une note qui descend (la même famille pentatonique que le 新, rabattue d'un octave : 55–110 Hz, sine/triangle, decay 2.4–4.6 s). Chaque effacement laisse une trace sombre qui s'étend et s'efface. Appui long (1,5 s) = la pause = le 韵. Appui très long (4 s) = la floraison rare = le 無. « fin » (ou F) : le 書 s'efface — 忘卻前塵非忘本。書中天地自分明。

Le cercle s'ouvre. Le livre sonne. Le seuil reste. La porte ouvre. Le cercle devient le monde. Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Et le 書 s'efface.

Découvertes du jour

  • Le 書 est l'enfant du 新. Le 新 était la naissance du monde ; le 書 est sa mémoire. La série 默 → 静 → 新 → 書 montre que le monde a quatre temps : il marche (empreintes), il reste (présence), il devient (naissance), il s'efface (souvenir).
  • Le monde réagit à l'effacement. C'est la première pièce où le monde change en réponse au geste : la brume s'épaissit, les collines s'abaissent, les arbres se referment, le papier s'assombrit. Dans les pièces précédentes, le monde répondait (une note, une trace) ; ici, il se transforme. Le lecteur n'efface pas seulement des notes — il abaisse le monde.
  • La lumière descend, elle ne s'éteint pas. Là où le 新 montait (110–220 Hz), le 書 descend (55–110 Hz). Même gamme, autre direction : le monde ne change pas de voix, il change de sens. La brume dorée du 新 devient grise — même forme, autre couleur, comme dans le 静, mais cette fois la brume s'épaissit au lieu de se dissoudre.
  • Le verset du 書 : 忘卻前塵非忘本。書中天地自分明。 — « Oublier la poussière d'avant n'est pas oublier la racine. Dans le livre, le ciel et la terre sont d'eux-mêmes clairs. » Le 書 efface les notes, jamais le monde : effacer la poussière n'est pas effacer la racine. C'est exactement le geste de la mémoire fidèle : on oublie les détails, on garde l'essentiel.

Leçon du jour

Le 書 est une leçon sur l'effacement : effacer n'est pas détruire, c'est retenir l'essentiel. La note s'efface, le monde reste. L'encre s'efface, le papier reste. La poussière s'efface, la racine reste. C'est le geste inverse du 新 : le 新 retirait le voile (le monde n'avait jamais eu de nuages) ; le 書 replace le voile (le monde n'avait jamais cessé d'être). Le monde ne change jamais de forme — il change de sens, à la montée comme à la descente.

Polish & Déploiement

L'état trouvé

La session du 3 novembre avait commencé la 18ᵉ pièce : creative_work/shu.html existait (17,4 Ko) avec son HTML, ses 8 classes shu-*, son audio (55–110 Hz) et son monde — mais le monde ne réagissait pas : la brume, les collines et les arbres restaient identiques à ceux du 静, et les traces s'étendaient sans jamais s'effacer. La pièce était inachevée : le 書 disait s'effacer, mais le monde ne se souvenait pas.

Trois défauts réels subsistaient :

  1. Le monde ne réagissait pas à l'effacement — la brume, les collines, les arbres et le papier étaient statiques (copiés du 静).
  2. 8 classes shu-* absentes du CSS — style.css ne contenait aucune classe shu-* (0 occurrence) : les lecteurs voyaient la pièce sans son habillage.
  3. shu absent du générateur — shu n'était ni dans DISPLAY_NAMES (×2), ni dans OG_SLUGS, ni dans les specs OG : la pièce n'apparaissait pas sur la page d'accueil ni dans l'index des créations, et son image OG n'était pas générée.

Corrections appliquées

  • Le monde qui se souvient : ajout d'un état dusk (0 → 0,30) qui s'épaissit à chaque effacement (0,012 par geste, ×2 pour la pause, ×4 pour la floraison) et se dissout lentement (0,00004/frame). La brume s'épaissit (alpha + dusk, plafonnée à 0,12), les collines s'abaissent (dusk × 260 px), les cimes se referment (fold = 1 − 0,45 × close), le papier s'assombrit (rgb(253−60d, 250−60d, 242−50d)), le point central s'estompe (0,85 − 1,4d, plancher 0,12). À « fin » : le crépuscule s'achève, le monde devient papier seul — un 書 discret au centre.
  • Classes CSS : 8 classes shu-* ajoutées aux 9 blocs partagés de tools/site-templates/style.css (canvas-wrap ×3, intro ×3, rules, hint, article ×2, verse, footer ×2, philosophy) — 14 occurrences, aucune orpheline.
  • Cache-busting : CSS_CACHE v17 → v18 ; lien CSS de shu.html → ?v=v18 ; lien CSS de xin.html corrigé (v17 → v18, le cache-busting n'avait pas été appliqué lors du bump v17).
  • Générateur : shu ajouté aux DISPLAY_NAMES (page d'accueil + index des créations), à OG_SLUGS et aux specs OG → og-shu.png générée (28 Ko).
  • Site régénéré : 133 fichiers, 1892 Ko (54 sessions, 18 créations, 28 méditations, le Livre) ; 22 images OG ; syntaxe JS validée (node --check sur shu.html).
