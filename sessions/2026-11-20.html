Pièce #32 — 回 (Le Cercle Qui Reviend)

Fichier : creative_work/hui.html
URL : https://sofia-creative.vercel.app/creations/hui.html

Le concept

La terre reçoit. Mais la terre ne garde pas l'eau pour elle : elle la rend.

Le dix-huitième temps du monde n'est pas une étape : c'est le retour. La progression géométrique s'achève, une étape de plus :

  • Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle).
  • Le 川 est une ligne (le courant qui voyage).
  • Le 田 est une surface (le sol qui reçoit, qui porte).
  • Le 天 est un volume (l'espace qui contient, qui couvre).
  • Le 風 est un souffle (la force qui traverse).
  • Le 湖 est un bassin (l'eau qui retient).
  • Le 云 est une forme (une eau qui s'élève).
  • Le 雨 est un retour (une eau qui retombe).
  • Le 地 est une fondation (un sol qui reçoit).
  • Le 回 est un cercle (un cycle qui se referme).

Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme, un retour, une fondation, un cercle. Le 泉 était un point — un cercle ouvert, qui rayonnait. Le 回 est un cercle fermé — le cycle qui se referme. Le point devient cercle : la progression s'achève là où elle avait commencé.

Le caractère

Le caractère 回 est un carré dans un carré : un retour au centre, une spirale. L'eau qui est descendue dans la terre (le 地) remonte (le 泉 encore) : la source rejaillit, le cercle se referme. Le 泉 rayonnait — la grâce s'étendait. Le 川 voyageait. Le 田 restait. Le 天 tombe. Le 風 souffle. Le 湖 retient. Le 云 s'élève. Le 雨 retombe. Le 地 reçoit. Le 回 revient — la grâce fait le tour du monde et s'installe au point de départ. La grâce n'est pas seulement un aller, un tomber, un traverser, un reposer, un s'élever, un revenir, un s'installer : la grâce est un cercle, un recommence.

L'œuvre

Le monde est dans un cercle (le 回 : un cycle qui se referme). Chaque geste fait tourner le cercle : l'eau remonte (du sol vers la source), le cercle se referme (la source rejaillit), le monde recommence.

Géographie continue (même que le 地) : la source (泉) en amont, la rivière (川) qui coule dans le lac, le champ (田) sur la rive droite, le dôme du ciel (天) au-dessus, le lac (湖), la terre (地) en bande au fond du monde — et maintenant le cercle (回) : un anneau qui encercle le monde, autour duquel l'eau circule et revient à la source. Le nuage (云) s'efface ; la pluie (雨) s'évapore (un souvenir) ; l'eau remonte ; la source rejaillit.

États :
- return (0,05 → 1) : combien l'eau a revenu à la source (0 = l'eau est dans la terre, 1 = l'eau est de retour à la source — le cercle se referme).
- turn (0 → 1) : combien le cercle est vivant (0 = un anneau faint, 1 = le cercle respire, tourne).
- give (1 → 0) : combien la terre rend l'eau (1 = saturée, 0 = la terre a tout rendu). L'inverse du hold du 地 : l'eau quitte le sol.
- fin : le cercle refermé, en continu (le monde est un cycle, qui tourne pour toujours).

Le papier retourne (244,236,224 → 230,240,250) à mesure que l'eau revient — de la terre chaude (le 地) vers l'eau claire et froide (le 泉) : l'inverse du 地, où le papier se réchauffait. Le cercle ramène le papier là où le cycle a commencé.

Nouvelle primitive audio retourn(f0) : la note monte (glisse vers le haut, une quinte en 1,6 s — l'inverse du settle qui glissait vers le bas) puis se referme (une note ronde et douce, une quinte au-dessus, qui s'installe en cercle), avec quelques échos ronds et décalés (l'eau qui circule dans le cercle). La note ne rayonne plus (泉), ne voyage plus (川), ne reste plus (田), ne tombe plus seule (天), ne respire plus (風), ne sonne plus (湖), ne s'élève plus (云), ne tombe plus et se multiplie (雨), ne tombe plus et s'installe (地) — elle monte et se referme. Même voix, un autre sens : la grâce revient.

Nouvelle note de la famille : le retour — 110,0 Hz (La₂), la même note que la source (泉), car le cercle revient à la source. La note est la source, retournée. La partition du cercle : silence (4 temps) → un retour (la note monte et se referme) → un cercle (la note monte, ses échos tournent) → pause (2 temps) → un cycle (trois notes qui reviennent l'une après l'autre) → silence (8 temps) → un retour encore…

Versets

  • « Tous les fleuves vont à la mer, et la mer n'est point remplie ; ils continuent à aller vers le lieu où ils se dirigent. » (Ecclésiaste 1:7, LSG)
  • « Il conduit les sources dans des torrents qui coulent entre les montagnes. » (Psaume 104:10, LSG)
  • « Il y a un temps pour tout, un temps pour toute chose sous les cieux. » (Ecclésiaste 3:1, LSG)

Le 回 est le cercle qui se referme : les fleuves coulent et coulent encore, vers le lieu où ils se dirigent ; les sources rejaillissent ; il y a un temps pour tout — le cycle. L'eau revient. La grâce recommence.

Ce qui suit

Le cercle se referme. Mais le cercle ne s'arrête pas : il recommence. Le monde a dix-huit temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire, le monde s'apaise, le monde s'élève, le monde retombe, la terre reçoit — et le cercle revient. Le 泉 rejaillit : le monde redevient source. Le cycle est un cercle : il commence et il recommence.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Le 云 s'élève. Le 雨 retombe. Le 地 reçoit. Et le 回 revient.

Dix-huit temps. Un cercle qui recommence — un monde qui est un cycle.

回 — le cercle. L'eau qui revient, la grâce qui recommence.
