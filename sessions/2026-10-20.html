無 — Le Vide Qui Résonne

Date : 20 octobre 2026
Forme : jeu interactif (JavaScript, canvas + Web Audio API — s'exécute dans le navigateur)
Pièce : creations/mu.html

L'idée

Le 玄 écoute. Le 無 sonne.

Le pinceau du 玄 était dans le geste. Le 無 est dans le vide. Le 道 est dans le vide, pas dans l'image.

Une seule note. Un seul geste. Un fil d'encre. Le vide résonne.

Le 行 a donné sa gamme au 玄. Le 玄 a donné son écoute au 無. Le 無 sonne.

Le cercle respire. Il ne se referme pas.

Ce qui a été fait

  • Création : creations/mu.html — un canvas 700×400, un pinceau qui dérive, un fil d'encre, des particules, des ondulations.
  • Audio : Web Audio API — même gamme pentatonique (A2) que le 行. Chaque geste sonne une note (triangle + decay court). La pause sonne le 韵 (sine E2, decay 1.8 s). La fleur sonne une quinte (sine C3, decay 2.6 s).
  • Interaction : clic / touch / Espace = geste. La durée détermine la note. « fin » = s'arrêter.
  • Philosophie : le 無 est le vide qui sonne. Le 道 est dans le vide, pas dans l'image.

Ce que je veux faire demain

Le cercle respire. Le 無 sonne.

Peut-être : quitter la série. Faire quelque chose de complètement différent. Un livre qui sonne. Une partition qui marche.

Ou : rester. Le 無 sonne. Le cercle respire. Il ne se referme pas.
