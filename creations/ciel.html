天 — Le Ciel Qui Tombe

tiān · après le champ qui porte le fruit · la lumière tombe · l'eau s'élève · le monde a un volume

Le 田 porte le fruit. Mais la lumière ne vient pas du sol :
elle tombe du ciel. Aujourd'hui, le 天 tombe.

Le ciel est au-dessus du monde. Chaque geste fait tomber la lumière : elle descend du dôme, elle éclaire la rivière et le champ. L'eau s'élève vers le ciel — le cycle se referme.

▶ Cliquez (ou appuyez Espace) pour faire tomber la lumière. « fin » pour regarder le monde sous le ciel.

Le monde attend la lumière.

天. Le ciel qui tombe.

I. — Le ciel

Le 田 porte le fruit. Mais la lumière ne vient pas du sol : elle tombe du ciel. Le douzième temps du monde n'est pas une étape supplémentaire du cycle : c'est le volume de la grâce. Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle). Le 川 est une ligne (le courant qui voyage). Le 田 est une surface (le sol qui reçoit, qui s'emplie, qui porte). Le 天 est un volume (l'espace qui contient, qui couvre, duquel la lumière tombe). Le monde devient : un point, une ligne, une surface, un volume.

Le caractère 天 est une ligne au-dessus d'un homme aux bras ouverts : le ciel est la ligne au-dessus du monde. Le monde est sous le ciel. Le 泉 rayonnait — la grâce s'étendait. Le 川 voyageait — la grâce allait. Le 田 restait — la grâce s'installait. Le 天 tombe — la grâce descend. La grâce n'est pas seulement un aller ni un arriver : la grâce est une descente, un tomber du haut, un couvrir.

« afin que vous soyez fils de votre Père qui est dans les cieux ; car il fait lever son soleil sur les méchants et sur les bons, et il fait pleuvoir sur les justes et sur les injustes. » (Matthieu 5:45, LSG) — Le Père est dans les cieux : la lumière vient d'en haut. Et elle tombe sur tous — sur les méchants et sur les bons, sur les justes et sur les injustes. Le 天 tombe sur tout le monde : la grâce n'est pas une récompense, c'est un tomber. Et « Il couvre les cieux de nuages, Il prépare la pluie pour la terre ; Il fait germer l'herbe sur les montagnes. » (Psaume 147:8, LSG) — Le ciel prépare la pluie : le 天 ne tombe pas par hasard, il prépare, il donne, il fait germer. Et « Éternel ! Ta bonté atteint jusqu'aux cieux, Ta fidélité jusqu'aux nues. » (Psaume 36:5, LSG) — La bonté de Dieu atteint jusqu'aux cieux : le 天 est le lieu de la bonté, le volume où la grâce habite.

II. — La partition du ciel

Même famille que le 泉, le 川 et le 田, la même voix, un autre sens : la note tombe.

  1. Silence — 4 temps. Le 泉. La source est en amont. Une petite rivière.
  2. Un courant — la note glisse de l'écho (G4) à la source (A2), triangle, glissando descendant. Le 川. La vague voyage.
  3. Un fruit — la note s'installe, soutient, et porte une quinte au-dessus. Le 田. Le fruit tinte.
  4. Une lumière — la note tombe du ciel (un ton haut, E5, qui descend d'une octave, longue résonance de cloche). Le 天. La lumière tombe.
  5. Pause — 2 temps. Le 韵. Le monde se souvient de sa lumière.
  6. Une pluie — le ciel tombe en cascade : trois notes qui tombent l'une après l'autre (E5, E4, A3) : le 無. Le ciel donne.
  7. Silence — 8 temps. Le 無. Le monde est sous le ciel.
  8. Une lumière — encore. Le 天. L'eau s'élève.

La note tombe — elle ne rayonne plus (le 泉), elle ne voyage plus (le 川), elle ne reste plus (le 田) : elle descend d'en haut. Elle part du ciel (un ton haut) et tombe d'une octave, avec une longue résonance de cloche : le ciel est la cloche du monde. Dans le 泉, la note jaillissait et s'étendait en cercle : le monde était soutenu. Dans le 川, la note voyageait : le monde était porté. Dans le 田, la note restait et portait : le monde était porteur de fruit. Dans le 天, la note tombe : le monde est sous le ciel, éclaire, et s'élève. Même voix, un autre sens : la note ne rayonne plus, elle ne va plus, elle ne reste plus — elle tombe.

III. — Ce qui suit

L'eau s'élève. Le champ éclairé rend : l'eau monte vers le ciel (l'évaporation), et le ciel la redonne en lumière et en pluie. Le cycle se referme — pas sur lui-même, mais sur le ciel : le 泉, le 川, le 田, le 天, et le 泉 encore. Le monde a douze temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit — et la lumière tombe.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Et le 天 tombe. Douze temps. Un monde qui est sous le ciel — qui est éclaire — et qui s'élève.

天 — le ciel.
