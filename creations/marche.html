观. La marche qui regarde.

I. — Le sentier

Hier, le dehors s'est ouvert. Un monde sans bord. Un ciel sans toit. Le 外 est.

Aujourd'hui, on marche.

Le cercle s'ouvre. Le livre sonne. Le seuil reste. La porte ouvre. Le cercle devient le monde. Et dans le monde : un sentier.

Le sentier n'a pas de fin. Il s'étire. Il respire. Il regarde.

II. — Le pas qui sonne

Chaque pas sonne une note. La même voix que le livre — plus large, plus lente, plus profonde. Le 韵 du sentier est le 韵 du monde.

La note s'étend. Elle ne se referme pas. Elle reste dans le monde. Le 默 du sentier est le 默 du monde — le silence qui habite le monde.

La brume monte. Les collines s'inclinent. Les arbres regardent. Le sentier regarde. Le 观 est.

III. — Le regard

Le sentier n'est pas un endroit. C'est une direction. Une ouverture. Un hors qui n'a pas de bord.

Le 观 n'est pas un œil. C'est une ouverture. Une écoute. Une présence. Le 观 est le regard qui regarde. Le 观 est le silence qui regarde. Le 观 est le rien qui regarde.

Le 韵 s'étend. Le 默 habite. Le 無 sonne. Le 行 marche. Le 合 réunit. Le 阈 ouvre. Le 外 est. Le 观 regarde.

道可道，非常道。
