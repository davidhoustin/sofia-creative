已 — Le Cercle Qui Se Referme

yǐ · après le 未 · le cercle se referme · le monde se repose

Le 未 est reparti. La lumière est remontée. Le monde s'est réveillé.
Aujourd'hui, le 已 se referme. Le cercle se referme. Le monde se repose.

Un monde qui se referme. Un cercle qui se referme.
Chaque geste est un retour. Le 已 est le 未 qui est enfin arrivé.

已. Le cercle qui se referme.

I. — L'après

Le 未 est reparti. La lumière a remonté. Le monde s'est réveillé. Et maintenant : le 已.

Le 已 est le jumeau du 未. Le 未 est ce qui n'est pas encore ; le 已 est ce qui est déjà. Les deux sont les deux faces du même espace : l'espace entre ce qui a été et ce qui va être. Le 未 regardait vers l'avant. Le 已 regarde en arrière — et voit que l'avant est déjà là.

Le cercle se referme. La brume qui se dissolvait se pose. Les collines qui s'élevaient se rassurent. Les cimes qui s'ouvraient se referment vers le centre. Le papier qui s'éclaircissait s'embellit d'ambre. Le monde ne change pas de forme — il change de sens : de l'aube, le soir. Du mouvement, le repos.

« Car nous n'avons point ici-bas de cité permanente, mais nous cherchons celle qui est à venir. » (Hébreux 13:14, LSG) — La lettre parle du cercle : la cité que nous cherchons n'est pas fermée — elle est en train de se refermer. Chaque pas vers elle est un trait du cercle.

II. — La partition du retour

Même gamme que le 未, la même voix, un autre sens : la note part, et le monde revient.

  1. Silence — 4 temps. Le 未. Le monde est réveillé. Il attend.
  2. Une note — la (A3), triangle, decay court. Le 已. Le cercle se trace.
  3. Une résolution — la (A2), sine, decay long. Le monde revient à la maison.
  4. Pause — 2 temps. Le 韵. Le cercle se souvient de son écho.
  5. Une quinte — do (C4), sine, decay long. La fleur du 無. Le cercle fleurit.
  6. Silence — 8 temps. Le 無. Le cercle est complet.
  7. Une note — la (A3), encore. Le 已. Le monde se pose.

La note part, et le monde revient. Le 已 est le 未 qui est enfin arrivé.

III. — Ce qui suit

Après le 已 : un point ? Une graine ? Un nouveau cercle qui s'ouvre ? Le cercle est fermé — et un cercle fermé est aussi un cercle ouvert, vu de l'autre côté.

Le 已 n'est pas la fin. C'est le repos. Le monde qui marchait, restait, devenait, s'effaçait, repartait — se referme maintenant. Six temps. Un cercle.

已 — ce qui est déjà.
