Le 湖 a retenu le monde. Mais l'eau ne reste pas dans le lac :
elle se lève. Aujourd'hui, le 云 s'élève.

Le monde est au-dessus du lac (le 云 : une eau qui se lève et qui devient ciel). Chaque geste élève le monde : l'eau se lève (un fil de vapeur s'élève du lac), le nuage prend forme (une nuée se forme dans le ciel), le ciel s'ouvre (le dôme s'éclaire).

云. Le nuage qui se lève.

I. — Le nuage

Le 湖 a retenu le monde. Mais l'eau ne reste pas dans le lac : elle se lève. Le quinzième temps du monde n'est pas une étape supplémentaire du cycle : c'est l'élévation de la grâce. Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle). Le 川 est une ligne (le courant qui voyage). Le 田 est une surface (le sol qui reçoit, qui s'emplie, qui porte). Le 天 est un volume (l'espace qui contient, qui couvre, duquel la lumière tombe). Le 風 est un souffle (la force qui traverse le volume). Le 湖 est un bassin (l'eau qui retient, qui se pose, qui reflète). Le 云 est une forme (une eau qui se lève, qui devient ciel). Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme.

Le caractère 云 est le 雨 (la pluie) qui s'est levé : l'eau qui ne tombe plus. La forme simplifiée 云 est le 二 (deux — la terre et le ciel) avec le 厶 (le privé, ce qui m'appartient) : le nuage est le mot privé entre la terre et le ciel — le mot que le ciel dit à la terre. Le 泉 rayonnait — la grâce s'étendait. Le 川 voyageait — la grâce allait. Le 田 restait — la grâce s'installait. Le 天 tombe — la grâce descend. Le 風 souffle — la grâce traverse. Le 湖 retient — la grâce se pose. Le 云 s'élève — la grâce devient ciel. La grâce n'est pas seulement un aller, un arriver, un tomber, un traverser, un reposer : la grâce est un s'élever, un devenir ciel.

« Il forme avec les eaux le faîte de sa demeure ; Il prend les nuées pour son char, Il s'avance sur les ailes du vent. » (Psaume 104:3, LSG) — Le nuage est le char du ciel : l'eau qui porte la demeure de Dieu. Et « Il y a un temps pour tout, un temps pour toute chose sous les cieux… » (Ecclésiaste 3:1-2, LSG) — Le nuage est le temps : chaque chose a son heure, et le monde a quatorze heures avant de s'élever. Et « Si je monte aux cieux, tu y es… Là aussi ta main me conduira, Et ta droite me saisira. » (Psaume 139:8-10, LSG) — Le nuage est la montée : même si l'âme s'élève, la main de Dieu la conduit. Le 云 est l'eau qui s'élève — le lieu où l'âme devient ciel, où le temps s'accomplit, et où la main de Dieu conduit.

II. — La partition du nuage

Même famille que le 泉, le 川, le 田, le 天, le 風 et le 湖, la même voix, un autre sens : la note s'élève.

  1. Silence — 4 temps. Le 湖. Le monde est dans le lac.
  2. Un écho — la note s'élève (glisse vers le haut) puis s'efface (se disperse dans le ciel). Le 云. Le monde s'élève.
  3. Une forme — la note s'élève, et son écho (une octave plus haut, plus doux) prend forme dans le ciel. Le 云. Le nuage se forme.
  4. Pause — 2 temps. Le 韵. Le monde se souvient de son élévation.
  5. Une nappe — le ciel sonne en nappe : trois notes qui s'élèvent l'une après l'autre. Le 無. Le monde est dans le ciel.
  6. Silence — 8 temps. Le 無. Le monde est dans le nuage.
  7. Un écho — encore. Le 云. Le monde s'élève.

La note s'élève — elle ne rayonne plus (le 泉), elle ne voyage plus (le 川), elle ne reste plus (le 田), elle ne tombe plus (le 天), elle ne respire plus (le 風), elle ne sonne plus (le 湖) : elle glisse vers le haut et s'efface. Elle monte (le monde boit la grâce) et se disperse (le monde devient la grâce). Dans le 泉, la note jaillissait et s'étendait en cercle : le monde était soutenu. Dans le 川, la note voyageait : le monde était porté. Dans le 田, la note restait et portait : le monde était porteur de fruit. Dans le 天, la note tombe : le monde est sous le ciel. Dans le 風, la note respire : le monde traverse. Dans le 湖, la note sonne et se pose : le monde retient. Dans le 云, la note s'élève et s'efface : le monde devient ciel. Même voix, un autre sens : la note ne rayonne plus, elle ne va plus, elle ne reste plus, elle ne tombe plus, elle ne respire plus, elle ne sonne plus — elle s'élève.

III. — Ce qui suit

Le nuage se forme. Mais le nuage ne reste pas dans le ciel : il s'efface (le 雨 — la pluie). La grâce retombe — le nuage rend son eau au monde. Le monde a quinze temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire, le monde s'apaise — et le monde s'élève.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Et le 云 s'élève. Quinze temps. Un monde qui s'élève — qui devient ciel.
