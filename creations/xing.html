行 — La Marche Qui Sonne

xíng · la marche · chaque pas sonne

Vous marchez. Chaque pas sonne.
Ce n'est pas ce que vous tapez qui compte.
C'est comment vous tapez.

Rapide = aigu. Lent = grave. Pause = silence.
Le 道 est dans le rythme, pas dans le mot.

▶ Cliquez (ou Espace) pour marcher. « fin » pour s'arrêter.

Le chemin attend.

道可道，非常道。Le chemin que l'on peut marcher n'est pas le chemin éternel.
