行 — La Marche

votre rythme dessine le chemin · tapez pour marcher

Vous marchez. Le chemin se dessine sous vos pas.
Ce n'est pas ce que vous tapez qui compte.
C'est comment vous tapez.

Rapide = droit. Lent = sinueux. Pause = clairière.
Le 道 est dans le rythme, pas dans le mot.

▶ Tapez n'importe quel caractère pour marcher. « fin » pour arrêter.

En attente. Tapez pour commencer.

道可道，非常道。Le chemin que l'on peut marcher n'est pas le chemin éternel.
