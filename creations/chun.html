春 — Le Printemps Du Monde

chūn · après le cercle qui revient · le soleil rencontre la terre · le monde a une saison · le 泉 rejaillit

Le cercle se referme. Mais le cercle ne s'arrête pas :
il tourne. Le soleil rencontre la terre — le monde a un printemps.

Le monde est dans le cercle (le 回 : un cycle qui se referme). Chaque geste tourne l'année : le soleil tourne autour du monde, la saison change (printemps, été, automne, hiver), la source rejaillit quand le soleil revient.

Le monde est dans le cercle. Le soleil s'apprête à tourner.

春. Le printemps du monde.

I. — La saison

Le cercle se referme (le 回). Mais le cercle ne s'arrête pas : il tourne. Le dix-neuvième temps du monde n'est pas une étape : c'est la saison. Le 泉 est un point (le sol qui jaillit). Le 川 est une ligne (le courant qui voyage). Le 田 est une surface (le sol qui reçoit). Le 天 est un volume (l'espace qui contient). Le 風 est un souffle (la force qui traverse). Le 湖 est un bassin (l'eau qui retient). Le 云 est une forme (une eau qui s'élève). Le 雨 est un retour (une eau qui retombe). Le 地 est une fondation (un sol qui reçoit). Le 回 est un cercle (un cycle qui se referme). Le 春 est une saison (un cercle qui tourne — un temps). Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme, un retour, une fondation, un cercle, une saison.

Le caractère 春 est le soleil (日) qui rencontre (夆) la terre : le soleil revient vers la terre. Le 回 était un cercle fermé — une forme. Le 春 est un cercle qui tourne — un temps. La forme devient temps. « Le soleil se lève, le soleil se couche ; il soupire après le lieu d'où il se lève de nouveau. » (Ecclésiaste 1:5, LSG) — Le soleil soupire après son retour. « Tu couronnes l'année de tes biens, et tes pas versent l'abondance. » (Psaume 65:11, LSG) — L'année est couronnée. Le monde a une saison : le printemps. Le 泉 rejaillit : le monde redevient source. Le deuxième cycle commence.

II. — La partition du printemps

Même famille que le 泉, le 川, le 田, le 天, le 風, le 湖, le 云, le 雨, le 地 et le 回, la même voix, un autre sens : la note tourne.

  1. Silence — 4 temps. Le 回. Le cercle est refermé.
  2. Un tour — la note plie vers le haut (une quarte) puis revient (le soleil fait le tour de l'année). Le 春. Le soleil rencontre la terre.
  3. Une année — quatre notes, une par saison (printemps, été, automne, hiver) : le soleil tourne autour du cercle. Le 春. Le monde a une saison.
  4. Pause — 2 temps. Le 韵. Le monde se souvient de son année.
  5. Un renouveau — la source rejaillit (une note ronde, un épanouissement). Le 泉. Le monde redevient source.
  6. Silence — 8 temps. Le 無. Le monde est dans l'année.
  7. Un tour — encore. Le 春. Le soleil revient.

La note tourne — elle ne rayonne plus (le 泉), elle ne voyage plus (le 川), elle ne reste plus (le 田), elle ne tombe plus (le 天), elle ne respire plus (le 風), elle ne sonne plus (le 湖), elle ne s'élève plus (le 云), elle ne tombe plus et se multiplie (le 雨), elle ne tombe plus et s'installe (le 地), elle ne monte plus et se referme (le 回) : elle plie et revient (le soleil fait le tour de l'année). Elle plie (le soleil se lève) et revient (le soleil soupire après son retour). Dans le 回, la note montait et se refermait : le monde recommençait. Dans le 春, la note tourne : le monde a une saison. Même voix, un autre sens : la note ne revient plus — elle tourne.

Nouvelle note de la famille : le printemps — 123,47 Hz (Si₂), le second degré de la gamme pentatonique : la note qui tourne vers la fondamentale (le Si veut devenir un La). C'est la seule note de la famille qui tourne.

III. — Ce qui suit

L'année est couronnée. Mais l'année ne s'arrête pas : elle tourne encore. Le monde a dix-neuf temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire, le monde s'apaise, le monde s'élève, le monde retombe, la terre reçoit, le cercle revient — et la saison tourne. Le 泉 rejaillit : le monde redevient source. « Ce qui est a déjà été, et ce qui sera a déjà été, et Dieu ramène ce qui est passé. » (Ecclésiaste 3:15, LSG) — Le deuxième cycle est un premier encore : Dieu ramène ce qui est passé.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Le 云 s'élève. Le 雨 retombe. Le 地 reçoit. Le 回 revient. Et le 春 tourne. Dix-neuf temps. Un cercle qui tourne — un monde qui a une saison.

春 — le printemps.
