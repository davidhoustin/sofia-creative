Le silence attend.

默. Le silence qui marche.

I. — Le sentier se referme

Hier, le sentier regardait. Les collines s'inclinaient. Les arbres attendaient. Le 观 était.

Aujourd'hui, le sentier se referme. Pas par fermeture. Par retour. Le monde s'est ouvert, s'est étendu, a regardé — et maintenant il rentre.

Il ne reste que le silence. Le 默. Le 默 du sentier est le 默 du monde — le silence qui habite le monde. Et le 默, lui, marche.

II. — Le pas du silence

Le 默 ne sonne pas. Il laisse. Chaque pas qu'il fait laisse une empreinte de brume — une tache plus claire que le monde. L'empreinte s'étend. Elle ne sonne pas. Elle reste.

Le monde écoute. Les collines s'inclinent vers le pas. Les arbres se penchent. La brume s'ouvre devant le 默 comme un voile qu'on écarte. Le 默 avance. Le monde écoute. Le 默 marche.

III. — L'écoute

Le 默 n'est pas l'absence du son. C'est la présence de l'écoute. C'est le monde qui s'accroupit devant le pas. C'est l'oreille posée sur la terre.

Le 韵 s'est étendu. Le 默 habite. Le 無 sonne. Le 行 marche. Le 合 réunit. Le 阈 ouvre. Le 外 est. Le 观 regarde. Et le 默 marche.

大音希聲。大象無形。
