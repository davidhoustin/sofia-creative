I. — Le champ qui se souvient

La rivière se souvient (le 川, deuxième temps). Mais la rivière ne s'arrête pas : elle coule (川流不息). Son eau s'infiltre dans le champ. Et le champ porte le fruit encore — mais maintenant il se souvient du premier fruit. Le vingt-et-unième temps du monde n'est pas une étape : c'est la moisson. Le 泉 est un point (le sol qui jaillit). Le 川 est une ligne (le courant qui voyage). Le 田 est une surface (le sol qui reçoit). Le 天 est un volume (l'espace qui contient). Le 風 est un souffle (la force qui traverse). Le 湖 est un bassin (l'eau qui retient). Le 云 est une forme (une eau qui s'élève). Le 雨 est un retour (une eau qui retombe). Le 地 est une fondation (un sol qui reçoit). Le 回 est un cercle (un cycle qui se referme). Le 春 est une saison (un cercle qui tourne). Le 川, encore, est une mémoire (une ligne qui revient à elle-même). Le 田, encore, est une moisson (une surface qui porte le fruit encore). Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme, un retour, une fondation, un cercle, une saison, une mémoire, une moisson.

Le caractère 田 est un carré à croix — un champ divisé en quatre cases. Le premier 田 recevait l'eau et portait le fruit (la surface qui reçoit). Le deuxième 田 se souvient : il porte le fruit encore, et maintenant il porte la mémoire du premier fruit — le champ est plus riche. Le premier 田 recevait ; le deuxième 田 se souvient (il redonne, plus abondamment). « Je suis le cep, vous êtes les sarments. Celui qui demeure en moi et en qui je demeure porte beaucoup de fruit, car sans moi vous ne pouvez rien faire. » (Jean 15:5, LSG) — Le sarment demeure (il se souvient de sa racine) et porte beaucoup de fruit : le champ qui se souvient porte plus de fruit. « Tu couronnes l'année de tes biens, et tes pas versent l'abondance. » (Psaume 65:11, LSG) — L'année est couronnée : le champ se souvient de l'année, et l'abondance coule de ses pas. « Lorsque tu mangeras et te rassasieras, tu béniras l'Éternel, ton Dieu, pour le bon pays qu'il t'a donné. » (Deutéronome 8:10, LSG) — Le monde mange et s'acharne à remercier : le champ qui se souvient bénit — la moisson est une mémoire qui rend grâce.

II. — La partition du champ qui se souvient

Même famille que le 泉, le 川, le 田, le 天, le 風, le 湖, le 云, le 雨, le 地, le 回, le 春 et la rivière qui se souvient, la même voix, un autre sens : la note s'installe, elle porte, et elle se souvient.

  1. Silence — 4 temps. Le 春. La source rejaillit (le deuxième cycle continue).
  2. Un fruit — la note s'installe (attaque lente), soutient, porte une quinte au-dessus (le fruit tinte), et porte une note plus profonde (le premier fruit, revenu de la terre). Le 田, deuxième temps. Le champ se souvient.
  3. Une année — quatre notes, une par saison (printemps, été, automne, hiver), chacune revenue (chacune s'installe, porte, et se souvient) : le champ chante la moisson. Le 田, deuxième temps. Le champ se souvient de l'année.
  4. Pause — 2 temps. Le 韵. Le champ porte.
  5. Un courant — la note glisse du champ (La₂) à la rivière (Do₃) : la mémoire du fruit revient à l'eau (la rivière la porte vers la source). Le 田, deuxième temps, et le 川, premier temps.
  6. Silence — 8 temps. Le 無. Le champ porte le fruit.
  7. Un fruit — encore. Le 田, deuxième temps. Le champ se souvient.

La note s'installe (comme le premier 田), soutient, et porte une quinte au-dessus (le fruit tinte) — mais maintenant elle porte aussi une note plus profonde (une quarte en dessous : le premier fruit, revenu de la terre). Elle ne rayonne plus (le 泉), ne voyage plus (le 川), ne se souvient plus en descendant (la rivière, deuxième temps) : elle s'installe, porte, et se souvient (le premier fruit est sous le fruit présent — la mémoire est plus profonde que la moisson). Dans le premier 田, la note s'installait et portait : le monde portait le fruit. Dans le 田, deuxième temps, la note s'installe, porte, et se souvient : le monde se souvient du premier fruit. Même voix, un autre sens : la note se souvient.

Nouvelle note de la famille : le champ qui se souvient — 110,00 Hz (La₂), la même note que la source (le champ est arrosé par la source) : le champ porte la note de la source. Le fruit tinte une quinte au-dessus (Mi₃, 164,81 Hz). La mémoire est une quarte en dessous (Mi₁, 82,41 Hz — la note de la terre) : le premier fruit est profond, dans la terre (la graine est retombée dans le sol). C'est la seule note de la famille qui porte et se souvient à la fois.

III. — Ce qui suit

Le champ se souvient du premier fruit. Mais le champ ne s'arrête pas : il continue de porter. Le monde a vingt-et-un temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire, le monde s'apaise, le monde s'élève, le monde retombe, la terre reçoit, le cercle revient, la saison tourne, la rivière se souvient — et le champ se souvient du premier fruit. Le deuxième cycle continue : le 天 encore (le ciel du deuxième monde — la lumière qui retombe sur le monde en cycle : la grâce retombe, et le monde se souvient de la première lumière).

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Le 云 s'élève. Le 雨 retombe. Le 地 reçoit. Le 回 revient. Le 春 tourne. Le 川 se souvient. Et le 田 se souvient du premier fruit. Vingt-et-un temps. Un champ qui se souvient — un monde qui porte le fruit.
