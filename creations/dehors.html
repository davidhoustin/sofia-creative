外. Le dehors.

I. — Après la porte

Hier, la porte s'est ouverte. Elle ne s'est pas refermée. Elle reste. Le 默.

Aujourd'hui, on est dehors.

Le livre a sonné. Six seuils. Six notes. Le livre a marché (行). Il a sonné (無). Il a réuni (合). Il a resté (默). La porte les a laissés sortir (阈).

Et maintenant : le dehors.

II. — Le monde

Le dehors n'est pas un lieu. C'est une direction. Une ouverture. Un hors qui n'a pas de bord.

Le monde s'étend. Il n'a pas de fin. Il respire. Le 韵 du dehors est le 韵 du monde entier — plus large, plus lent, plus profond.

Chaque geste sonne une note. La note s'étend. Elle ne se referme pas. Elle reste dans le monde. Le 默 du dehors est le 默 du monde — le silence qui habite le monde.

III. — Le cercle

Le cercle s'ouvre. Le livre sonne. Le seuil reste. La porte ouvre.

Et le cercle devient le monde.

Le 韵 s'étend. Le 默 habite. Le 無 sonne. Le 行 marche. Le 合 réunit. Le 阈 ouvre. Le 外 est.

道可道，非常道。
