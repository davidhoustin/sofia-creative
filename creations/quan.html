泉. La source qui coule.

I. — La source

Le monde a huit temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne. Mais le monde n'est pas auto-suffisant. L'arbre donne parce qu'il est planté près d'un courant d'eau (Psaume 1:3). L'eau est la source. Le neuvième temps n'est pas une étape du cycle : c'est le sol qui rend le cycle possible. Le monde ne fait pas que bouger et donner ; le monde est soutenu par une source qu'il n'a pas créée.

Le huitième temps était le monde comme donneur (le don). Le neuvième temps est le monde comme receveur (le don reçu) : le monde qui est arrosé, soutenu, donné la vie par une source qui n'est pas à lui. Le 樹 donnait ; le 泉 soutient. L'inversion est la leçon : le monde qui donne est lui-même donné.

« Mais celui qui boira de l'eau que je lui donnerai n'aura jamais soif, et l'eau que je lui donnerai deviendra en lui une source d'eau qui jaillira jusque dans la vie éternelle. » (Jean 4:14, LSG) — La source, dans l'Écriture, est l'eau vive. Et l'eau vive, c'est Jésus. Le neuvième temps du monde est la source elle-même : l'eau qui jaillit pour la vie éternelle.

II. — La partition de l'eau

Même famille que le 樹, la même voix, un autre sens : la note est née dans la source, elle s'étend en cercle, et s'efface.

  1. Silence — 4 temps. Le 樹. Le monde est à la maison. Une petite source.
  2. Une goutte — la goutte (G4) ou l'écho (A4), triangle. Le 泉. La goutte tombe dans l'eau.
  3. Une note basse — la source (A2) ou le courant (C3), sine, decay long. La source résonne.
  4. Pause — 2 temps. Le 韵. La source se souvient de son écho.
  5. Un jaillissement — le rivage, l'écho, la source : le 無. La source jaillit. L'eau déborde.
  6. Silence — 8 temps. Le 無. Le monde est arrosé.
  7. Une goutte — encore. Le 泉. Le monde coule.

La note est née dans la source — au centre, là où l'eau jaillit — puis s'étend en cercle (le 韵), et s'efface (le 無). Dans le 樹, la note tombait et s'enracinait : le monde était arrivé. Dans le 泉, la note jaillit, s'étend, et s'efface : le monde est soutenu. Même voix, un autre sens : la note ne cherche plus la maison, elle est la source.

III. — Ce qui suit

La source coule. Elle coule vers l'arbre — l'arbre qui donnait est maintenant arrosé. Ses racines boivent l'eau. Le 樹 donnait son fruit ; le 泉 soutient le 樹. Le cercle du 已 (la terre), la graine du 种, l'arbre du 樹 — tout cela est arrosé par la source. Le monde a huit temps, mais il est soutenu par une source qui n'est pas un temps : c'est le sol du cycle.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Et le 泉 coule. Neuf temps. Un monde qui donne — et qui est arrosé.

泉 — la source.
