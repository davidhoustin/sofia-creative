破默之园

pò mò zhī yuán · le jardin qui casse le silence

Le silence est là.
Le 道 s'est arrêté.

Tapez un mot pour le casser.
Le mot devient une graine.
La graine pousse.

(ou « fin » pour laisser le silence)

Le silence est intact.
