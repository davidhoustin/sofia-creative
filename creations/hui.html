回 — Le Cercle Qui Reviend

La terre reçoit. Mais elle ne garde pas l'eau pour elle :
elle la rend. Aujourd'hui, le 回 revient.

Le monde est un cercle (le 回 : un cycle qui se referme). Chaque geste fait tourner le cercle : l'eau remonte (du sol vers la source), le cercle se referme (la source rejaillit), le monde recommence.

Le monde est dans la terre. L'eau s'apprête à remonter.

回. Le cercle qui revient.

I. — Le cercle

La terre reçoit. Mais la terre ne garde pas l'eau pour elle : elle la rend. Le dix-huitième temps du monde n'est pas une étape : c'est le retour. Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle). Le 川 est une ligne (le courant qui voyage). Le 田 est une surface (le sol qui reçoit, qui porte). Le 天 est un volume (l'espace qui contient, qui couvre). Le 風 est un souffle (la force qui traverse). Le 湖 est un bassin (l'eau qui retient). Le 云 est une forme (une eau qui s'élève). Le 雨 est un retour (une eau qui retombe). Le 地 est une fondation (un sol qui reçoit). Le 回 est un cercle (un cycle qui se referme). Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin, une forme, un retour, une fondation, un cercle.

Le caractère 回 est un carré dans un carré : un retour au centre, une spirale. L'eau qui est descendue dans la terre (le 地) remonte (le 泉 encore) : la source rejaillit, le cercle se referme. Le 泉 rayonnait — la grâce s'étendait. Le 川 voyageait. Le 田 restait. Le 天 tombait. Le 風 soufflait. Le 湖 retenait. Le 云 s'élevait. Le 雨 retombait. Le 地 recevait. Le 回 revient — la grâce fait le tour du monde et s'installe au point de départ. La grâce n'est pas seulement un aller, un tomber, un traverser, un reposer, un s'élever, un revenir, un s'installer : la grâce est un cercle, un recommence. « Tous les fleuves vont à la mer, et la mer n'est point remplie ; ils continuent à aller vers le lieu où ils se dirigent. » (Ecclésiaste 1:7, LSG) — L'eau coule et coule encore, vers le lieu où elle se dirige : le cercle. Et « Il conduit les sources dans des torrents qui coulent entre les montagnes. » (Psaume 104:10, LSG) — Les sources rejaillissent : l'eau qui est descendue remonte. Le 回 est le cercle qui se referme — le lieu où la grâce recommence.

II. — La partition du cercle

Même famille que le 泉, le 川, le 田, le 天, le 風, le 湖, le 云, le 雨 et le 地, la même voix, un autre sens : la note monte et se referme.

  1. Silence — 4 temps. Le 地. Le monde est dans la terre.
  2. Un retour — la note monte (glisse vers le haut) puis se referme (une note ronde et douce). Le 回. L'eau revient.
  3. Un cercle — la note monte, et ses échos (plus doux, ronds, décalés) tournent en cercle. Le 回. Le cercle se referme.
  4. Pause — 2 temps. Le 韵. Le monde se souvient de son cercle.
  5. Un cycle — le cercle tourne en fond : trois notes qui reviennent l'une après l'autre. Le 無. Le monde est un cycle fermé.
  6. Silence — 8 temps. Le 無. Le monde est dans le cercle.
  7. Un retour — encore. Le 回. L'eau revient.

La note monte et se referme — elle ne rayonne plus (le 泉), elle ne voyage plus (le 川), elle ne reste plus (le 田), elle ne tombe plus seule (le 天), elle ne respire plus (le 風), elle ne sonne plus (le 湖), elle ne s'élève plus (le 云), elle ne tombe plus et se multiplie (le 雨), elle ne tombe plus et s'installe (le 地) : elle glisse vers le haut (l'eau remonte vers la source) et se referme (le cercle se referme). Elle monte (le monde redevient source) et se referme (le monde recommence). Dans le 地, la note tombait et s'installait : le monde était nourri. Dans le 回, la note monte et se referme : le monde recommence. Même voix, un autre sens : la note ne va plus, elle ne tombe plus — elle revient.

III. — Ce qui suit

Le cercle se referme. Mais le cercle ne s'arrête pas : il recommence. Le monde a dix-huit temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire, le monde s'apaise, le monde s'élève, le monde retombe, la terre reçoit — et le cercle revient. Le 泉 rejaillit : le monde redevient source. « Il y a un temps pour tout, un temps pour toute chose sous les cieux. » (Ecclésiaste 3:1, LSG) — Le cycle est un cercle : il commence et il recommence.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Le 湖 retient. Le 云 s'élève. Le 雨 retombe. Le 地 reçoit. Et le 回 revient. Dix-huit temps. Un cercle qui recommence — un monde qui est un cycle.

回 — le cercle.
