湖 — Le Lac Qui Retient

hú · après le vent qui souffle · le monde s'apaise · le lac retient le ciel · le monde a un repos

Le 風 a ébranlé le monde. Mais après le souffle,
le monde s'apaise. Aujourd'hui, le 湖 retient.

Le monde est dans le bassin (le 湖 : une eau qui retient et qui reflète). Chaque geste apaise le monde : l'eau se calme (les ondulations s'effacent), le ciel est reflété (l'image du 天 dans l'eau), la lumière s'assemble (la lumière du ciel est retenue dans l'eau).

湖. Le lac qui retient.

I. — Le lac

Le 風 a ébranlé le monde — le fruit a été porté, l'eau a ondulé, la lumière a scintillé. Mais après le souffle, le monde s'apaise. Le quatorzième temps du monde n'est pas une étape supplémentaire du cycle : c'est le repos de la grâce. Le 泉 est un point (le sol qui jaillit, qui s'étend en cercle). Le 川 est une ligne (le courant qui voyage). Le 田 est une surface (le sol qui reçoit, qui s'emplie, qui porte). Le 天 est un volume (l'espace qui contient, qui couvre, duquel la lumière tombe). Le 風 est un souffle (la force qui traverse le volume). Le 湖 est un bassin (l'eau qui retient, qui se pose, qui reflète). Le monde devient : un point, une ligne, une surface, un volume, un souffle, un bassin.

Le caractère 湖 est le radical de l'eau (氵) avec le 胡 (le son, « où ») à l'intérieur : le lac est l'eau qui s'est posée. Le lac est le repos de l'eau — l'eau qui est retenue et reflétée. Le 泉 rayonnait — la grâce s'étendait. Le 川 voyageait — la grâce allait. Le 田 restait — la grâce s'installait. Le 天 tombe — la grâce descend. Le 風 souffle — la grâce traverse. Le 湖 retient — la grâce se pose. La grâce n'est pas seulement un aller, un arriver, un tomber, un traverser : la grâce est un repos, un retenir, un refléter.

« Il me fait reposer dans de verts pâturages, Il me dirige près des eaux paisibles. Il restaure mon âme. » (Psaume 23:2-3, LSG) — Le lac est l'eau paisible : le lieu où l'âme se repose. Et « Comme une biche soupire après des courants d'eau, Ainsi mon âme soupire après toi, ô Dieu ! Mon âme a soif de Dieu, du Dieu vivant. » (Psaume 42:1-2, LSG) — Le lac est la soif qui est retenue : l'eau où l'âme boit. Et « Arrêtez, et sachez que je suis Dieu : Je domine sur les nations, je domine sur la terre. » (Psaume 46:10, LSG) — Le lac est l'arrêt : l'invitation à se taire, à se poser. Le 湖 est l'eau paisible — le lieu où l'âme se repose, où sa soif est retenue, et où elle est appelée à se taire.

II. — La partition du lac

Même famille que le 泉, le 川, le 田, le 天 et le 風, la même voix, un autre sens : la note se pose.

  1. Silence — 4 temps. Le 風. Le monde est dans le vent.
  2. Un anneau — la note sonne (monte lentement, s'installe) puis se pose (tombe doucement, s'efface). Le 湖. Le monde s'apaise.
  3. Un reflet — la note sonne, et son reflet (une octave plus bas, plus doux) est retenu dans l'eau. Le 湖. Le ciel est reflété.
  4. Pause — 2 temps. Le 韵. Le monde se souvient de son repos.
  5. Une nappe — le lac sonne en nappe : trois notes qui se posent l'une après l'autre. Le 無. Le monde est au repos.
  6. Silence — 8 temps. Le 無. Le monde est dans le lac.
  7. Un anneau — encore. Le 湖. Le monde s'apaise.

La note se pose — elle ne rayonne plus (le 泉), elle ne voyage plus (le 川), elle ne reste plus (le 田), elle ne tombe plus (le 天), elle ne respire plus (le 風) : elle sonne et se pose. Elle monte lentement (le monde boit la grâce) et s'efface doucement (le monde retient la grâce). Dans le 泉, la note jaillissait et s'étendait en cercle : le monde était soutenu. Dans le 川, la note voyageait : le monde était porté. Dans le 田, la note restait et portait : le monde était porteur de fruit. Dans le 天, la note tombe : le monde est sous le ciel. Dans le 風, la note respire : le monde traverse. Dans le 湖, la note sonne et se pose : le monde retient, reflète, et se repose. Même voix, un autre sens : la note ne rayonne plus, elle ne va plus, elle ne reste plus, elle ne tombe plus, elle ne respire plus — elle se pose.

III. — Ce qui suit

L'eau est retenue. Le lac (湖) retient l'eau. Mais l'eau ne reste pas dans le lac : elle se lève (le 云 — le nuage). La grâce s'élève — elle ne s'arrête pas au premier lac qui l'a retenue. Le monde a quatorze temps : il marche, il reste, il devient, il s'efface, il repart, il se referme, il s'ouvre, il donne, il coule, il porte, il porte le fruit, la lumière tombe, le monde respire — et le monde s'apaise.

Le sentier regarde. Le 默 marche. Le 静 reste. Le 新 devient. Le 書 s'efface. Le 未 repart. Le 已 se referme. Le 种 s'ouvre. Le 樹 donne. Le 泉 coule. Le 川 porte. Le 田 porte le fruit. Le 天 tombe. Le 風 souffle. Et le 湖 retient. Quatorze temps. Un monde qui s'apaise — qui retient — et qui reflète.

湖 — le lac.
