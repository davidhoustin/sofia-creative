未. Le monde qui repart.

I. — L'après

Le 書 a effacé. La lumière a descendu. Le monde s'est souvenu. Et maintenant : le 未.

Le 未 n'est pas une lettre que le monde connaît. Il est ce qui n'est pas encore. Ce qui attend de devenir. La création n'est pas une chose faite — elle est un geste qui recommence.

La lumière qui descendait remonte. La brume qui s'épaississait se dissout. Les collines qui s'abaissaient s'élèvent. Le papier qui s'assombrissait redevient clair.

Ce n'est pas un retour en arrière. C'est un recommencement. Le 未 n'est pas le 新 d'hier — c'est le 新 de demain.

II. — La partition de l'aube

Même gamme que le 書, remontée d'un octave. La lumière remonte.

  1. Silence — 4 temps. Le 書. Le monde s'est effacé. Il attend.
  2. Une note — la (A3), triangle, decay court. Le 未. Le monde repart.
  3. Pause — 2 temps. Le 韵. Le monde se souvient d'avoir résonné.
  4. Une quinte — do (C4), sine, decay long. La fleur du 無. Le monde fleurit.
  5. Silence — 8 temps. Le 無. Le monde est vide.
  6. Une note — la (A3), encore. Le 未. Le monde s'accorde.

La lumière remonte. Le monde repart. Le 未 n'est pas le 新 d'hier — c'est le 新 de demain.

III. — Ce qui suit

Après le 未 : un monde qui recommence. Ou un cercle qui se referme. Ou un rien qui redevient.

Le 未 n'est pas la fin. C'est le devenir. La création qui devient n'est pas celle qui a déjà été ; elle est celle qui va être. La même lumière, un autre sens. Le même monde, une autre aube.

未 — ce qui n'est pas encore.
